# Code of Conduct

This project follows a simple standard: be professional, be kind, be precise.

## Expected behavior

- Assume good faith; disagree about ideas, not people.
- Keep discussions technical and on-topic.
- Accept constructive criticism and precise language about defects — the codebase is designed to fail loudly, and conversations should too (politely).

## Unacceptable behavior

- Harassment, personal attacks, or demeaning comments.
- Publishing other people's private information without consent.
- Trolling, baiting, or sustained disruption of discussion.

## Enforcement

The repository owner moderates issues and pull requests. Violations may result in edits, closure, or bans. Report problems by contacting the repository owner directly.

This code is adapted in spirit from the Contributor Covenant; the full text is not reproduced because this project's community is small — the standard is not.
